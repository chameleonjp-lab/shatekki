## 3. 全効果に適用する条件

### 3.1 発動時点、同時発生、再付与

「飛行終了後」は、その射の元弾と分裂弾の飛行がすべて終わり、店主の質問がある場合は回答を受け付けた後の安全な処理点を指す。変化後の落下を進める前に、予約効果を確定する。新しい100効果を、その効果を得た射の飛行中へ割り込ませない。

「次射」は、上記の処理点で設定を予約し、次の位置選び・装填・照準と実際に発射する1回へ適用する意味である。発射が成立した時だけ予約を消費し、その元弾と分裂弾へ設定を引き継ぐ。位置の選び直し、停止、演出省略では消費しない。全ての弾数処理後に残弾0でゲームが終わる場合は予約も終了し、強化だけを理由に弾を生み出さない。

弾の損傷倍率、押す倍率、速さ、重力、弾種など、**同じ設定項目は最後の指定で上書き**する。別の項目は併用できる。例えば「損傷1.25倍」の後に「損傷1.5倍」を得ても1.875倍にはしない。複数項目を変える効果は、その行に記した項目だけを上書きする。

この上書きは設定値に適用する。弾数の増減は [本文§8](2026-11-06-expanded-gameplay-requirements.md#8-一射の順序と同時発生) に従い、予約順に各要求を一度ずつ処理する。各要求に固有番号を付け、同じ要求の再処理では加減しない。背景36マスは元弾・分裂弾・反射による再接触を含め各ゲーム1回であり、別マスに同じ効果番号が割り当たることは禁止しない。既存装置の「一射1回」と混同しない。

候補の抽選、適用可能性の判定順、対象なしの案内は本文§5.2・§6.2・§8に従う。本書では個々の効果が使えない条件を示す。背景に割当済みの効果を別効果へ引き直さず、質問から得た効果も再描画・再読み込みで引き直さない。新効果から別の効果や質問を再帰的に発生させない。

| 項目 | 既存の参照値と本案での扱い |

| 損傷・押す力 | 通常の計算を基準に、新効果の倍率は各0.5〜1.5倍の範囲に制限する提案。既存威力板の倍率と合わせる部分は `min(4, 威力板倍率 × 新効果倍率)` として、既存 `MAX_POWER_MULTIPLIER = 4` を越えない。装填・弾種・耐久値0の扱いは既存の計算順を維持する。 |

上の新倍率・制限式は試作用の提案であり、`rules-v1` の正式データへ書き戻さない。本文の36枠案と一緒に負荷・獲得数・点数分布を測った後、別ルール版として採否を決める。

### 3.3 景品の種類変更

FX041〜FX060は、36枠全体に残る未獲得個体を指定シリーズへ変え、以後の補充先もそのシリーズにする。獲得済み個体、空き枠、補充延期中で個体のない枠を変化対象にしない。対象が画面外でも処理する。種類の抽選方法と形の適合確認は本文§4.2・§7.1に従い、系列外へ黙って逃がさない。

全ての種類変更で、個体番号、所属枠、位置、姿勢、直線速度、角速度、耐久値の残り割合を維持する。台に固定中なら固定状態・位相を保ち、すでに外れた個体を再固定しない。新しい種類の周期運動は新規補充時から使う。形・質量・最大耐久値など種類に属する値は変更先を参照するが、現在の移動状態を初期位置へ戻さない。

同じ個体へ複数の種類変更が予約された場合、最終種類を決めてから形を一度だけ更新し、最初の変更前の耐久率へ新しい最大耐久値を掛けて四捨五入する。変更後の落下は当該射に含め、回収された時の種類で獲得・セットを判定する。種類が変わっただけでは回収や加点をしない。

形が重なる個体は本文§7.1どおり変更を延期する。延期した内容も後の有効な変更で上書きし、獲得済みになった個体の予約は破棄する。補充は既存D30を維持し、塞がった枠を空けるために未獲得景品を消したり移動したりしない。現行コードは固定中の景品を変身候補から除外するため、この全残存個体の仕様には後続の実装修正が必要である。

FX090〜FX092の個別変化にも同じ引継ぎと延期の条件を適用する。ただし、これらは品揃えシリーズや以後の補充先を変更しない。個別変化がシリーズ外の種類を作る場合は、一時的な例外であることを効果結果に示す。

### 3.4 縁と情報の表示

FX061〜FX080で選ぶ縁表示のシリーズは、品揃えシリーズとは別に1つだけ保持する。指定シリーズに属する現在の全残存個体を、§2の同じ色・記号・ラベルで示す。補充・種類変更のたびに所属を見直し、獲得済みの景品は表示対象から外す。対象が今は0個でも指示を保持し、「対象の景品は今はありません」と案内する。次の縁表示指示またはゲーム終了で置き換える。

FX093〜FX100の案内は次射だけの追加表示であり、基本の残弾、通常の照準、全体図、未使用マス表示、セットの通常ヒントを隠さない。追加案内は一度に1種類とし、後の案内で上書きする。縁表示のシリーズは消さない。次射の確定またはゲーム終了で解除する。表示の省略・消音・言語変更で、物理や得点の結果を変えない。

## 4. 効果候補100件

表の倍率・個数・角度は提案値である。「次射がない」は、本文の順序で全ての弾数処理を終えた結果、次に発射する機会がない場合を指す。「再付与」は別の未使用マスや別の回答から正当に得た場合の扱いであり、同じ要求の二重処理を許す意味ではない。

## 5. 実装時に追加する記録と確認

本書は候補定義であり、現在の製品に次の記録があることを意味しない。実装担当は本文§9の保存項目に、次射の各設定と発射形態、追加案内の種類、FX091用の「個体を新規配置・補充した時の種類」を含める。個体の元種類は種類変更で上書きしない。FX092は既存の確定した獲得順序を参照する。延期した個別変化は、変更先の種類と個体番号を保存し、復帰時に対象を選び直さない。

FX099の道筋は当該射の表示用であり、全ゲームの再現機能を追加する提案ではない。飛行中にページが失われた場合は既存の中断規則を適用する。予測線・耐久率・角度等の表示は計算結果を説明するもので、画面を見た結果から得点や命中を書き換えない。
