# シャテッキ　36枠版の統合要件仕様書

2026年11月18日。対象は、夏祭りの射的屋台を縦画面で遊ぶ「シャテッキ／Shatekki」。公開用の9枠版を基準に、36枠の内部試作を、記録・遊び・見た目がそろった公開候補まで仕上げる。

**今回の担当決定**　ChatGPTがゲームの仕様、保存、物理判定、画面操作、3D美術、演出、効果音、翻訳、試験、PR提出後の失敗・競合の修正まで一貫して受け持つ。実装・統合にClaudeの作業や受領は必要ない。正式な数値の採用、確認ページと正式版の公開、PRのマージは利用者が判断する。

## 2　引き継ぐゲームの仕様

初期の[決定01〜33](../decision-log.md)と[追加指定D34〜D37](2026-11-06-expanded-gameplay-requirements.md)を基準とする。次の表の既存機能は、後続の変更でもプレイヤーが同じ結果を得る条件である。

| 対象 | プレイヤーから見た動作 |
|---|---|
| 棚と操作 | 公開用は3×3、拡張版は連続した3段×12列。景品は100種類。縦画面に約3列ずつ見せ、立ち位置を選ぶ→装填→照準→発射の順に進む。全体図は位置選びのときだけ移動に使え、それ以外は現在地を示す。画面外でも命中・回収を数える。 |
| 景品・連鎖・補充 | 景品は命中や耐久0だけでは獲得にならず、回収位置へ落ちた個体を1回数える。動く景品は周期を保つ。連鎖終了後、落下中には有限の猶予を1回与える。続行時は空いた枠を補充し、別の景品で塞がった枠は空くまで待つ。 |
| 弾と得点 | 初期10発、追加は累計10発、最大20射。分裂したコルクは発射回数に足さない。既存効果→補給A1〜A10の順で全件を処理し、最後の残弾で続行または終了する。得点は景品＋技＋セット−減点を一射単位で反映し、累計の下限は0点。最大連鎖は一射の獲得個体数の最大値。 |

| 店主・シリーズ（D35） | 1射の店主命中をまとめ、弾の飛行後に200問から1問・2択を表示する。回答待ちは停止し、有効な回答1回だけで、選んだ側の候補から効果を決める。部位別の初回加点と質問は別。20シリーズの品替えや対象表示では色に共通の印と名前を添える。 |

## 3　遊びの結果を守る

**保存と再開。** 発射記録を保存してから弾を消費した状態を画面に出し、飛行と音を始める。保存に失敗したら発射せず、「再試行」を同じ一射として扱う。精算時は残弾、獲得、得点、使用済み、注文、抽選状態、補充、図鑑、自己ベスト、終了結果をまとめて確定する。最後の一発で旧＋2札と袋が重なり追加枠があと1なら、旧札で＋1、袋は＋0。残弾1で続行し、袋の達成と＋0の理由も読める。

同じ回を2画面で操作しても勝った側だけが進む。ほかの画面で「見る」だけでは進行を中断しない。射撃の合間から再開できる。飛行・質問・落下中の再読込は明示的に中断を確定し、同じ弾の撃ち直しを認めない。終了・中断結果を読み直し、明示的に閉じて次のゲームを始められる。保存できないときの「この画面だけで遊ぶ」は新規の回であり、進行・ベスト・図鑑・おみやげ・送信待ちへの永続書込みは0件とする。

**版と記録。** 9枠正式版とr001〜r003を比較用に保つ。新内部版を保存r004→品替えr005→時計r006の順に分ける。途中の回や試作スコアを別版へ移さない。旧図鑑は同じ識別子と組合せの発見を参照し、旧キーを保存前後で照合する。名前・音量・言語・識別値・旧ベスト・送信待ちを保護する。通常と日替わりの進行、ベスト、図鑑を区分し、おみやげ3枠だけは両者で共用する。日替わりのベストは開始日単位、図鑑は日替わり内で日をまたいで保持する。

**品替えと日替わり。** 棚に支えられている景品は、形が変わっても底の高さ・向き・耐久割合・元の運動を保つ。落下中や支持面不明なら姿勢を維持し、上の棚や隣の運動範囲と重なる場合は同じ候補を再抽選せず延期する。新しく補充した景品には新種類の運動を使う。同じ日・版・ゲーム内時刻に同じ操作をしたら、言語・画面の更新速度が違っても各射の獲得、得点、残弾、質問、効果、抽選状態が一致する。日付をまたいで再開したときは開始日、新規プレイでは当日の屋台を使う。

## 4　画面・屋台・演出・音

夕暮れの祭り屋台の木の棚、赤白の幕、提灯の暖色と景品の明るい輪郭を引き継ぐ。短い縦画面でも、指で的を狙う場所、現在の残弾、次に押す操作を見分けられることを見た目の合格条件にする。既存の[美術方針](../design/visual-direction.md)、[素材台帳](../design/asset-manifest.md)、[音の台帳](../design/audio-ledger.md)を土台にChatGPTが制作・確認する。

| 画面 | 読めるもの・できる操作 |
|---|---|
| ホーム・設定 | 開始、遊び方、通常・今日の屋台、自己ベスト、図鑑、棚、音・言語、X共有。版にある機能だけを出す。最初の画面で開始を押せる。公開条件に合わせ、名前入力とランキング表示・通信を停止する。 |
| 射的・質問・一時停止 | 残弾・棚・照準・主操作が重ならず、左右端と上下段、店主を狙える。全体図には現在範囲と未使用／使用済みの記号を出す。質問は2択の全文と効果範囲が読め、1回だけ選べる。横向き・アプリ切替は停止し、縦復帰後に自分で再開できる。 |
| 精算・結果・図鑑 | 袋の個数、補給の実増加、終了理由を読める。結果の上部に総得点と再プレイを置き、下に獲得品、成立セット名、最大連鎖、内訳、ベストショット、最後の一射の効果、おみやげを置く。ホーム・X共有・図鑑往復を使える。結果の再読込で加算や初発見音を繰り返さない。 |

| 場面 | 何を見せ、何を合格とするか |
|---|---|
| P1 まとめ取り | 確定した獲得個体の小札が袋へ入る。個数が読め、1個は短い音、2〜3個は上がる木琴、4個以上は短い太鼓で締める。 |
| P2 初発見 | 成立したセットを絵・名前で示し、今回図鑑に初めて入った組だけに朱印を押す。複数なら1枚の札に件数をまとめ、各組を読める。 |
| P3 最後の一発から続行 | 発射前が残り1で、全効果の確定後に残弾が正なら、実際に得たコルクを弾入れに戻して「あと○発」と短い囃子を出す。上限で増えなければ理由を札に出す。 |
| P4 店主・背景 | 実際に品替えした景品の値札だけを返す。延期は数と理由、次射の予約は弾の横の印、使用済みのマスは記号と明暗で区別する。シリーズは色と印で識別する。 |
| P5 会心の装填 | 会心の装填が確定した瞬間に、照準を遮らず金具の刻みが一度そろい、既存の装填音と同期する。初射から働き、精算や次の入力を待たない。 |

大きな音と動きは一射に1場面。優先順は初発見→最後の一発から続行→まとめ取り。それ以外の成立は文字と数で読める。保存失敗・再試行・画面の再描画で、音・得点・弾を重複させない。音オフ・音量0・動きを減らす設定・演出省略でも、結果と次の入力を受ける時刻をそろえる。

美術の対象は、袋の付いた景品、反射で鳴る風鈴、景品を受けるシーソー、投入口が見える貯金箱、外周・中心を区別できる二重丸。通常・使用後・進捗をルールに合わせて描き、装飾が当たりを持つように見えないことを確かめる。画面端の方向表示を残し、値札・演出は指の操作を奪わない。
