## 2. プレイヤーの操作順

1. 「はじめる → すぐ狙える」。立ち位置は中央から始める。画面下左右の「◀」「▶」を1回押すと0.14 m、300 ms以上押し続けると毎秒1.4 mで、屋台の両端まで動く（候補の範囲は中央から±2.65 m）。端で止まり、押し直し不要。立ち位置を変えても、プレイヤーが決めた向きの値は維持する。銃口が横に移るため、実際に狙う場所は変わる。画面の向きは本人の照準入力だけに追従する。全体図は現在地と進捗の確認用。ホールド中の反対側入力を含め、2本目の指は受け付けない。
2. 射撃ボタン「撃つ」を押すと、その瞬間の位置・照準を固定してゲージを開始する。同じボタンは「発射」に変わる。ゲージは既存の往復する威力判定を使う。基準は1往復1.4秒、中心0.85。2回目のタップを受理した刻みで、威力の決定と弾1発の消費を1回にまとめて発射する。弱い位置でも飛ぶ。カメラと照準は手ブレ・鼓動・装填・効果・描画間隔で動かさない。別に「照準に戻る」で取り消せる。威力は押した刻みで決める。保存後に発射し、見た目のための待ち時間は加えない。
3. 飛行・質問・精算の間は位置と照準を固定。続行なら同じ位置と照準に戻り、左・右をすぐ使える。ポーズ、縦横の切替、アプリを離れる操作で長押しを解除する。ゲージ中に止まった場合はその位置で止まり、縦向きで明示再開。安定状態からの再読込では、ゲージを閉じ、最後に保存が成功した位置・照準に戻る。左右ボタンを離したときと照準枠の操作を終えたときに、それぞれの変更を一度保存する。中断した操作は最後の確定位置へ戻す。未確定の発射は既存の中断規則で扱う。

| 今の状態 | 受ける操作 | 次の状態 |
|---|---|---|
| 照準 | 左右・照準枠・「撃つ」・「店主と話す」・一時停止 | 「撃つ」で威力選び。「店主と話す」は落ち着いて狙えるときだけ開ける。移動・照準・会話を開く操作では弾を使わない。 |
| 自分から会話 | 「組み合わせのヒント」・「弾を1発もらう」・「閉じる」 | 確定または閉じたら照準へ。開いている間は移動・照準・発射を受けない。 |
| 威力選び | 「発射」・「照準に戻る」・一時停止 | 受理され保存された発射で飛行へ。取消で照準へ。 |
| 飛行・精算 | 演出省略・一時停止 | 必要なら質問へ。確定後、残弾が正なら照準、0なら結果。 |
| 質問 | 表示された2択・一時停止 | 1射に1問、同じ回答を一度だけ受け、精算へ。 |

### 手ブレに関わる既存効果の差し替え

次の射の会心・良好・普通の各範囲を、中心を動かさず倍率で拡大・縮小する。内部候補の値で、ゲージの範囲表示と判定が同じ値を使う。FX037・038などの速度変化とは同時適用できる。範囲倍率が複数なら最後の有効な予約を使い、FX082は従来どおり弾種・速度・追加案内も含む次射の設定を初期状態に戻し、範囲倍率も1へ戻す。弱判定は残りの範囲に対応する。狙っている方向は、どの効果でも変えない。

## 3. 背景と命中のルール

- 屋台内の背面14列×5段、左と右は各3列×5段で計100マス。景品棚の3段×12列はその手前に置く。背面には陳列列を挟む左右1列ずつ、上と下に1段ずつ足す。左右の内壁は背面から屋台の前端まで覆う。現行の射角では手前側に届かないため、銃口・左右の移動範囲・視点の振り幅を候補内で調整し、各面の奥・中央・手前を狙えるようにする。床・カウンター・天幕は前景の構造物として、素材別の命中と反射を持つ。照準の向きで見える屋台外の装飾は、色や枠が違う背景として描く。[描写と配置寸法](../design/2026-11-19-aim-first-stall-art.md)
- 36景品枠、効果の種類100、質問200問と2択、シリーズ20、セット2景品300組＋3景品100組、補給10種を、この候補の骨格にする。各マスへ開始時に1効果を割り当て、同じ効果の別マスは許す。通常プレイと日替わりは既存同様に別記録。枠も効果割当も保存で復元する。景品、店主、装置のほうが手前にあるならそちらの命中を処理する。未使用のマスは一度だけ効果を処理し、上限などで発動できない場合も使用済みにして理由を残す。使用済みのマスは当たった印と反射を返す。
- 一つの接触点は一つの対象として扱い、線や装飾の太さで当たり方を変えない。分裂、跳ね返りで後から別マスに当たったら別に数える。マスに景品や飾りが当たっても効果は出ない。弾の終着、点数、効果の順序と一括保存は従来の確定処理を使う。

## 4. 結果を見せる順序

| 射の結果 | 主な表示 | 一緒に読めるもの |
|---|---|---|
| セットが成立 | セット名・セットの加点・確定総得点。複数なら「3組完成」など、各組名と加点を下に並べ、初発見の組に印 | 取った個数、実際に増えた弾、上限で＋0だった理由。得点を再加算する処理はここに置かない。 |
| セット成立なし、景品獲得・補給・効果 | 成立した事実を表示。最後の1発から続けられるなら残弾を優先 | 変化先、延期、発動しなかった理由、実際の得点・残弾。 |
| 景品・装置・壁に接触し、獲得や新効果がない | 何に当たったかを返す。例「使ったマスで反射。隣の『？』にも効果があります」は、実際に近くに未使用マスがある場合だけ | 景品を押した場合はその名前、再接触では新しい補給が発生したかを区別。 |
| 何にも触れずに終わった | 軌道の終着に対応した具体的な一行。左／右に抜けたら棚中央側、上に抜けたら少し下、下に抜けたら少し上。手前・奥・時間切れはそれぞれ「屋台の内側」「手前の輪郭」「近い景品から」へ案内。出口が特定できなければ狙い・位置の見直し | 位置を戻す操作は本人が行う。得点・弾は確定した値どおり。 |

初期10発・追加上限10発・最大20射。大札は一射につき一回。同時に補給があれば、新旧の全発生元を集計した実増加を大札側の小さな行に残し、短い効果欄の「ほか○件」に任せない。確定した射には一つ以上の意味を残し、抑えた表示・音量0・早送りでも短文と結果が読める。得点の下限0は現行どおりで、セット加点の合計と一射の純増減は別に表示する。結果から最後の一射を読み返せる。

## 5. 店主と吹き出し

店主は射的屋台の右側に立つ。挨拶、操作、景品、仕掛け、状況に応じた案内の5分類、各20種。ゲーム開始後、台詞を出せる時間が6秒になったら最初を出す。その後は12秒間隔。同じ回の直近5件と、条件を満たさない台詞を除き、残りから一つを等確率で選ぶ。1件は4.5秒を目安に表示し、質問・停止で先に閉じる。落ち着いて狙える状態の時間だけ進める。飛行、装填のタイミング選び、質問、停止、裏タブ、上に読ませる内容があるときは止め、古い台詞をまとめて出さない。画面外にいる間は話者名を添えて画面上部へ置く。台詞も見た目も抽選、照準、時計、得点、補給に関わらない。

候補の公開前に100種を15言語で校正し、言い換えで数値・適用条件を変えない。

### 5.1 命中部位と持ち物の効果

| 当たった場所 | 各部位の初回点 | r007で加える効果 |
|---|---:|---|
| 帽子 | ＋30 | 初回だけ弾＋1を申し込む。現行の共通上限で判定し、上限なら「帽子 ＋30点／補給は上限」と出す。上限で得られなかった分も初回扱い。 |
| うちわ（既存の「扇子」部位） | ＋20 | 表面に当たるたび、面の向きに沿って棚へ跳ね返せる。縁・裏面は通常の接触。先に当たった面が表でも裏でも部位の初回点は同じ。 |
| 胴 | ＋10 | 初回の精算後に、その時点の2景品セットを一つ案内する。陳列や残弾は変えない。 |
| 足元 | ＋15 | 初回だけ次射の威力判定幅を1.25倍にする。会心・良好・普通の中心とゲージの速度は変えない。 |
| 盆の表面 | なし | 小さな反射面。うちわとは別の段の景品を狙える。盆だけの命中は店主の質問を出さない。 |

部位の点と初回効果は1ゲームに各1回。元弾・分裂弾が同じ部位に当たっても1回にまとめる。2回目以降も接触点の粒、部位の動き、当たった名前は出す。うちわ・盆を経由して景品を落としたときは、現行の反射取りの点を1景品につき1回計上する。盆への命中や反射だけで配点は増えない。景品が当たった場合は、部位の点・初回効果・質問のいずれも出さない。

飛行後の順序は「持ち越し→背景・既存装置→初回部位の効果→質問に答えた結果→既存の補給10種→残弾で続行・終了の判断」。得点と効果は一射の精算で確定する。足元は、基準に対する倍率を1.25で上書きする。その後に回答が幅を指定すれば回答を採用し、FX082なら基準へ戻る。胴のヒントは品替え・追加後の棚から選ぶ。初回部位の内訳を確定結果に残し、見出しの点数・弾の実増加・減少・確定残弾に反映する。幅が上書きされたり、続行できず消えたりしたときは、次射に残るかのように表示しない。

### 5.2 話し始める四つの場面

| 入口 | 条件 | 結果 |
|---|---|---|
| 自動の吹き出し | §5の間隔と表示条件を満たす | 100種の台詞のみ。 |
| 注文札 | ゲーム開始時の既存条件 | 既存の受ける／断る操作と達成報酬を維持する。 |
| 部位へ弾を当てる | 飛んだコルクが有効な部位に触れた射 | [200問の既存仕様](2026-11-06-expanded-gameplay-requirements.md#5-店主の質問200パターン)を維持する。飛行後、一射に1問。2択の適用可能な候補から1件を抽選し、増減弾・次射の変化・品揃え・縁の案内などを伝える。質問を出す時点で残弾0でも回答まで進める。同じ部位への2射目でも質問は出る。 |
| 「店主と話す」 | r007の安定した照準中、残弾あり。停止中・注文札や質問の表示中・操作や保存中は開けない | 1ゲームに1回だけ選択を確定できる。弾を撃たずに開き、固定の2択から選ぶ。 |

自分から話したときは次の選択を表示する。

| 選択 | 手に入るもの・条件 |
|---|---|
| 組み合わせのヒント | 2景品の組を一つ案内する。効果は案内のみ。陳列と残弾は変わらない。 |
| 弾を1発もらう | 共通上限内で即座に弾＋1。その代わり、次に実際に発射する1射は威力判定幅0.85倍。弾を増やせない場合と、既に幅の倍率が基準値1以外に予約済みの場合は選べる状態にせず理由を添える。他の次射設定は引き継ぐ。次射の表示と実際の判定に同じ倍率を使う。 |

各選択の効果と条件は選択前から読めるようにする。「閉じる」・回転・非表示・再読込で未選択の会話を閉じても権利を消費しない。操作と効果を保存できたときだけ使用済みにする。保存中は選択と発射を止め、明示的な取消も受け付けない。補給を保存した後に読み込み直しても、弾が二重に増えず、使っていない次射の条件を保持する。「撃つ」から照準に戻っただけでも条件を消費しない。使った選択と実結果は、リプレイでも読める結果欄に一度だけ表示する。会話だけで射数・得点・質問の順・乱数は進めない。通常・日替わりそれぞれ同じ条件。

セットの案内は、現在の棚に不足する種類が全部ある未成立の2景品セットのうち、既に1種類を取ったものを優先し、その中で登録ID順が先の1組を選ぶ。結果には組の名前と残りの景品名を記録する。2種類とも残る場合は両名を出す。該当がなければ「図鑑で、取った景品と組になる相手を確認できます」と案内する。胴は景品の追加・品替え後、自分からの会話は確定時の棚で選び、表示し直すときには同じ結果を使う。
