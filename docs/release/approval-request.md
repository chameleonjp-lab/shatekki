## 3. テスト用ページの公開

**公開先の候補**：`https://chameleonjp-lab.github.io/shatekki/`。これは実験場の資料にある新規ゲームの決まり（`https://chameleonjp-lab.github.io/<リポジトリ名>/`）から作った候補です。まだ存在しないURLのため、公開して実際に開けることを確かめるまでは、コードに正式URLとして入れません。
