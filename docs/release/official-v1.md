# 初回正式公開：ランキング非公開

2026-11-06、利用者が正式値採用・本体公開・DB適用を指示した。条件はランキング非公開、実験場へまだ連携しないこと。

## 採用した値

現行の全数値を変更せず、rules-v1として採用する。景品100種、セット100種、初期10発＋追加上限10発、9枠、既存の採点・物理・抽選・装填を維持する。セットを出しやすくする案Cは追加しない。

固定した全値は[data/release-approved-v1.json](../../data/release-approved-v1.json)。本番はsrc/catalog/release-config.tsからこのスナップショットを読む。試作データは試験用として残し、今後の試作調整で承認済み値が変わらないよう分けた。名称はプロジェクト名のシャテッキ／Shatekki。

## 非公開条件

ホームの名前入力・ランキング、結果の送信状態・本人順位・上位一覧を表示しない。開始・終了・再送・ランキング取得の通信も止める。過去の保存名・自己ベスト・図鑑・送信待ちは削除しない。新しく始めるゲームでは保存名を使わない。

public.gamesへの登録、実験場のページ変更、ランキング用の公開RPCや参加者表の追加は行わない。今回のDB適用はprivate.shatekki_releasesに正式値・版・書き出し元コミット・内容ハッシュを保存するもので、プレイヤー情報やスコアは保存しない。

## DBと公開の確認

非公開テーブルの移行を適用し、RLS有効・ポリシー0件・anon/authenticated/service_role権限なしを確認した。最終コードのコミットを取得した後、同じ正式値を100景品・100セットの参照とハッシュを検査して保存する。最終の登録結果はPR本文に記録する。同版の上書き・更新・削除・TRUNCATEを拒否し、修正値は次の版で保存する。

公開用の.github/workflows/pages.ymlを用意した。成功した最新mainのCI成果物だけを配信し、公開側で全試験やビルドを繰り返さない。mainへの変更はPRで提出し、マージは利用者が行う。

GitHub Pages設定を操作するブラウザは未認証。Google経由のサインインでaccounts.google.comへの画面アクセスが自動承認審査に拒否されたため、当該操作を停止した。追加の明示承認後に認証と公開設定の確認を再開する。到達確認前のURLを公開済みとは記録しない。

## 未確認

公開URLへの到達、Pages配信結果、iPhone Safari実機の操作・音・性能はまだ確認していない。自動試験やDB適用の成功を、公開・実機確認の完了とは扱わない。
