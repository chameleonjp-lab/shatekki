# 決定記録 — 屋台の射的ゲーム

作成日：2026年11月6日。対象：`chameleonjp-lab/shatekki`。

この会話でユーザーが「全て推奨で」と選択した26項目を記録する。選択肢の番号は前の提案と一致する。方式は確定しているが、採用値の実機調整や未定値の決定が終わったことを意味しない。

先に確定した前提は、景品100種類、隠しセット100種類、縦向きメイン、初期弾10発、空き場所への補充、ホーム・結果の共通機能を他ゲームとそろえること。

| 番号 | 項目 | 採用内容 |
|---|---|---|
| 01 | 補充の瞬間 | B：一射の反射・落下・連鎖を処理し終えた後、空き場所を補充する。 |
| 02 | 棚の景品数 | B：同時に9個。基本配置は3段×3個として縦画面で検証する。 |
| 03 | 景品の抽選 | B：種類と難易度の偏りを抑えたランダム抽選。 |
| 04 | 同じ景品の再出現 | B：同じ景品が連続出現しにくいように調整する。完全禁止にはしない。 |
| 05 | ゲームの終了 | A：撃てる弾がなくなり、最後の一射の連鎖・得点処理が完了した時に終了する。 |
| 06 | 景品の耐久値 | B：耐久値が0になると倒れやすくなる。棚から所定の回収位置へ落ちた時に獲得する。 |
| 07 | 装填威力 | B：耐久値への影響と景品を押す力の両方を変える。 |

| 11 | セットに必要な景品 | A：すべて3種類の景品を各1個獲得すると成立する。具体的な100セットは付録の候補を確認して決める。 |

## 読み替えが必要な旧版の表現

第3版の後半には、検討当時の「補充するか未定」「同時個数は別途」「実測心拍も未定」「横向きの遊べる範囲は別途」といった記述が残っている。現在は、この決定記録を優先する。

「随時補充」は落下直後の割り込み補充ではなく、一射の連鎖を処理した後の補充を意味する。「最大20発」は発射できる回数であり、分裂して飛んでいるコルクの総個数ではない。

具体的な景品名・セット名・組み合わせは候補一覧として引き継ぐ。26項目の承認だけで、候補名・点数・素材まで最終承認されたとは扱わない。
