## 1. 景品100種の導出規則（`runtime-config.ts`）

名前とカテゴリから、次の規則で機械的に決めた。個別に好みで調整した値ではない（動く景品の選定を除く）。

| 項目 | 規則 |
|---|---|
| 形・大きさ | 名前から外形を想定（箱／円柱／カプセル／球）。実寸4〜28cm。棚の枠の占有箱（幅0.30×高0.28×奥行0.26）に収まることを試験で確認。 |
| 質量 | 実物に近い値（g）に `PROTOTYPE_MASS_SCALE`（現在0.5）を掛ける。2gのコルクで動かせるかの調整用。実機で遊んで再調整する前提。 |
| 材質 | 名前から1つ（紙・プラ・木・布・金属・ガラス・陶器・ゴム）。 |
| 摩擦・反発 | 材質表（`MATERIAL_PHYSICS`）。 |
| 重心 | 縦横比>2で形の高さの+20%、>1.3で+10%、それ以外と球は中心。高いほど倒れやすい。 |
| 耐久値 | round(2 + 10×質量kg)（実物質量基準）を2〜8に丸める。 |
| 難易度 | 点数 = 質量kg×10 + 摩擦×2 + (低い形なら+1)。<2.1 easy、<3.4 normal、それ以上 hard。分布は easy 約35／normal 約40／hard 約25で、抽選の目標 3/4/2 に近い。 |
| 基本点 | easy 10、normal 20、hard 35。 |
| 動き | 100種のうち11種：風鈴(swing)、ミニ提灯(swing)、こま(spin)、金魚(slide)、カクレクマノミ(slide)、カニ(slide)、ミツバチ(slide)、ヨーヨー風船(bob)、紙風船(bob)、イルカ(bob)、チョウ(bob)。移動量は枠内に収まる範囲（slide：幅/2＋振幅 ≤ 0.15m）。 |
| 素材キー | 種類ID（例 `P001`）。 |

セット100種は候補JSONの3種の組合せをそのまま使う。加点は一律100点（試作）、ヒントは `set.<ID>.hint`。

## 3. 抽選の重み（Task 03）

- 重み = 難易度係数 × 直近係数。難易度係数 = 1.8^(目標数 − 棚の数)（差は±4で頭打ち）。直近係数 = 直近12回または棚にある種類は×0.25、それ以外は×1。
- 重みは常に有限で正（0にならない）。同じ種類の再出現は可能。セット完成を助ける補正は入れていない。
- 試験の許容：40シード×60回で、直近12回内の再出現率が、罰なし（×1.0）の率の60%未満（罰なしは5%〜20%に収まること）。基準は実行前に決めた。

## 4. 物理の手触り（Task 05/06 の確認）

下段中央の枠に1種類だけ置き、完璧な装填と正確な照準で、当たった位置を狙い直しながら最大6発撃って獲得までの発射数を測った（質量倍率0.5）。

- 1発で獲得 44種／2発 19／3発 15／4発 12／5発 2／6発 1／6発では獲得できない 7種（重い楽器・ぬいぐるみ類）。
- 難易度別の平均発射数：easy 1.2、normal 2.0、hard 5.0（6発で獲得できない場合は9として計算）。
- 倍率1.0（実物の質量）では軽い4〜5種を除き1発では動かず、10発で数個しか獲得できない見込みだったため0.5にした。0.75・1.0は同じ測り方では試していない（0.5と1.0の傾向のみ確認）。
- 照準のぶれ・装填の失敗・上段や端の枠は含まないため、実際の獲得率はこれより低い。実機で遊んで調整する前提。
- 耐久値が0になった景品は押す力1.8倍・摩擦0.6倍で、同じ一射でも大きく動く（耐久値0単独では獲得にならない）。台に固定された動く景品は、弱い一射では離れず、耐久値0または強い一射（押す力が基本の1.2倍以上）で台から外れる。

## 6. 仕掛け・得点・保存（Task 08〜10、第2波）

すべて試作。利用者が採用するまで正式値ではない。

### 仕掛け（Task 08、`src/sim/world.ts`、`src/core/gimmicks.ts`）

- 同じ装置は一射に1回（決定31）。元のコルクと分裂したコルクで使用済み記録を共有する。2回目以降の接触は通常の反射で、`ImpactEvent.target.activated` は false。
- 分裂（O08）：契約の「法線の周りに±回す」をそのまま回すと、真正面から当たったコルクの向きが変わらない。そのため試作では、反射後の向きを鉛直軸まわりに±`splitSpreadRad` 回して水平に開く（ほぼ真上に進む場合だけx軸まわり）。子は面の内側へ向かない。世代+1、反射回数・弾種・威力は親から引き継ぐ。世代上限（2）か同時コルク上限（8）で分裂できないときは、装置は使用済みになり、元のコルクがそのまま反射する。親が分裂で置き換わるときは `projectileEnded` を出さない（`projectileSpawned.parentId` で分かる）。
- 威力：倍率を `powerMultiplier` 倍、上限4。以後の命中すべてに効き、分裂した子にも引き継ぐ。
- 景品変更（O08）：予約し、全コルクが終わった後・settle の前に実行する。対象は `createTransformChooser(state, catalog)` が決める。(seed, shotId) から決まる乱数で、台に固定されていない未獲得の景品から一様に1個、変身先は現在の種類以外の全種類（100種）から一様に1種類。耐久値は `Math.round(残り÷最大 × 新しい最大)`（2/8→最大20→5）。物理は新しい種類の形・質量・重心・摩擦で作り直し、底面の高さと速度は引き継ぐ。変身後の落下も同じ一射で判定する。
- 弾種変更：次の一射だけ `bulletTypeCycle` の次（試作：今の弾種の次）。次の一射の後は標準に戻る。
- 追加弾：要求は `ammoBonus`（2）。累計上限10は core が適用し、追加弾を得た最後の一射は終了判定の前に弾が増える（AC18）。
- 減点：装置1つにつき `penaltyPoints`（30）を名目の減点として台帳に載せる。下限0の適用は決定28のとおり。
- 落下猶予（決定33）：既存の仕組み（settle が `maxSettleSec` に達した時点で落下中の景品があれば `fallGraceSec` だけ）を試験で確認した。猶予は一射1回、延長しない。一射の最長は `maxFlightSec + maxSettleSec + fallGraceSec`。

### 得点（Task 09、`src/core/scoring.ts`、`src/core/settlement.ts`）

- 技（O03、値は `PROTOTYPE_TUNING.scoring`）：連鎖は同じ一射で獲得した個体の2個目から1個につき+10。反射獲得は、獲得した景品に「反射済み（reflectionIndex>0）のコルク」が触れていれば1個につき+15。分裂獲得は、世代1以上のコルクが触れていれば1個につき+10。両方に当てはまれば両方加点する。
- 店主・隠し対象：ゲーム内の最初の1回だけ（決定18）。同じ一射の中の繰り返しも1回。
- セット：獲得時点の種類で判定。3種類をそろえた時点で成立、獲得済みの種類は消費しない。各セットは1ゲーム1回。加点は一律100（既存の試作値）。
- 台帳の項目ID：`chain:<shotId>`、`reflection:<instanceId>`、`split:<instanceId>`、セットはsetId、店主は部位名、隠し対象はtargetId、減点は装置ID。
