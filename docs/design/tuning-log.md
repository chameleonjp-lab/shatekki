# 調整記録（試作値）

すべて試作（prototype）。利用者が採用するまで正式値ではなく、正式ランキングの対象外（`isOfficialRankingEligible`）。値の持ち場所は `src/catalog/config.ts`（`PROTOTYPE_TUNING`）と `src/catalog/runtime-config.ts`（景品100種・セット100種）。担当：Game（Sonnet 5.5）。

## 1. 景品100種の導出規則（`runtime-config.ts`）

名前とカテゴリから、次の規則で機械的に決めた。個別に好みで調整した値ではない（動く景品の選定を除く）。

| 項目 | 規則 |
|---|---|
| 形・大きさ | 名前から外形を想定（箱／円柱／カプセル／球）。実寸4〜28cm。棚の枠の占有箱（幅0.30×高0.28×奥行0.26）に収まることを試験で確認。 |
| 質量 | 実物に近い値（g）に `PROTOTYPE_MASS_SCALE`（現在0.5）を掛ける。2gのコルクで動かせるかの調整用。実機で遊んで再調整する前提。 |
| 材質 | 名前から1つ（紙・プラ・木・布・金属・ガラス・陶器・ゴム）。 |
| 摩擦・反発 | 材質表（`MATERIAL_PHYSICS`）。 |
| 重心 | 縦横比>2で形の高さの+20%、>1.3で+10%、それ以外と球は中心。高いほど倒れやすい。 |
| 耐久値 | round(2 + 10×質量kg)（実物質量基準）を2〜8に丸める。 |
| 難易度 | 点数 = 質量kg×10 + 摩擦×2 + (低い形なら+1)。<2.1 easy、<3.4 normal、それ以上 hard。分布は easy 約35／normal 約40／hard 約25で、抽選の目標 3/4/2 に近い。 |
| 基本点 | easy 10、normal 20、hard 35。 |
| 動き | 100種のうち11種：風鈴(swing)、ミニ提灯(swing)、こま(spin)、金魚(slide)、カクレクマノミ(slide)、カニ(slide)、ミツバチ(slide)、ヨーヨー風船(bob)、紙風船(bob)、イルカ(bob)、チョウ(bob)。移動量は枠内に収まる範囲（slide：幅/2＋振幅 ≤ 0.15m）。 |
| 素材キー | 種類ID（例 `P001`）。 |

セット100種は候補JSONの3種の組合せをそのまま使う。加点は一律100点（試作）、ヒントは `set.<ID>.hint`。

## 2. 設定値（`PROTOTYPE_TUNING`）

`docs/architecture/shot-pipeline.md` §7 の試作値をそのまま入れた。追加で決めた点：

- 弾種：標準 すべて1倍。重い弾 損傷1.3・押す1.4・初速0.85・反発0.8。弾む弾 損傷0.8・押す0.8・初速1・反発1.3・追加反射+2。（O08・試作。契約には値が無かったため）
- 装填の weak 区分の `maxDistance` は 1（0〜1の全範囲を受ける）。

## 3. 抽選の重み（Task 03）

- 重み = 難易度係数 × 直近係数。難易度係数 = 1.8^(目標数 − 棚の数)（差は±4で頭打ち）。直近係数 = 直近12回または棚にある種類は×0.25、それ以外は×1。
- 重みは常に有限で正（0にならない）。同じ種類の再出現は可能。セット完成を助ける補正は入れていない。
- 試験の許容：40シード×60回で、直近12回内の再出現率が、罰なし（×1.0）の率の60%未満（罰なしは5%〜20%に収まること）。基準は実行前に決めた。
