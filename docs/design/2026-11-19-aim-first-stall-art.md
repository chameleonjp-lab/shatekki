# シャテッキ｜縦画面で見せる屋台、店主、命中、得点の描写

## 屋台と画面

夕暮れの祭り。目の前に、焦げ茶の木で組んだ12列×3段の景品棚。端の赤白幕と提灯は、店の奥行きと端を教える小さな目印になる。下の棚は少し手前、上の棚は少し奥。景品の輪郭は灯りで拾い、格子の細い線は景品より暗くする。プレイヤーの移動では屋台の正面を平行に横へ眺める。側面を狙う入力では視点もその角度へ向ける。照準入力が止まれば、画面も同じ向きで止まる。光源やカメラを揺らして動きを出す必要はない。

縦画面は上から残弾・得点、屋台、照準枠と操作の順。左右ボタンは操作欄の左右端に固定し、「撃つ／発射」は中央の同じ位置。指が照準や狙う景品に重なるのは照準枠内だけに抑える。44 CSS px以上の主操作、iPhone安全領域、402×874・402×700・375×600での上下余白を設計する。ゲージは操作欄の上端に収め、バーが光る面積と縁の短い刻みで段階を示す。強さは色に加えて文字と区画幅で伝える。装填が決まる瞬間に金具が合う絵を一度出し、発射に先立つ待ち時間を加えない。

## 奥のマス目

内壁の背面を左右まで、さらには両側面ともマス目にする。中央のマスは景品を邪魔しない生成色、端や上下は同じ明度帯でわずかに木目を変える。格子は面上に印刷した線。次の射に効く結果は、マス札と残弾の脇で共通の印・効果名を使う。後から別の効果で上書きされた場合は、新しい予約だけを残す。発動できるマスは角に小さな「？」。使用済みは一段暗くして「✓」。金・赤の大きな模様を全マスで点滅させず、命中したマスの印だけひっくり返る。静かな表示設定では瞬時に切り替える。

| 面 | 内側の寸法と分割 | 計 |
|---|---|---:|
| 背面 | `z=-2.45`、`x=-3.0…3.0`。中央12列の幅0.42 m（範囲±2.52）、両端は各0.48 m。 | 14列×5段＝70 |
| 左右壁 | `x=-3.0 / +3.0`、`z=-2.45…-0.15`を各3等分。 | 各3列×5段＝30 |
| 共通の段境界 | 下から `y=0 / 0.8 / 1.16 / 1.52 / 1.88 / 2.30` m。 | 合計100 |

移動端は±2.65 m、銃口の奥行きは `z=+0.35`、角度は左右±0.72、上下±0.70ラジアンを試作の出発点にする。現行の±0.3では左右壁の手前2列へ直射できない。右端で銃口から右壁まで0.35 m、側壁前端までは奥に0.50 mあるため、水平投影に必要な角度は約0.61ラジアンになる。弾道、カメラ、遮蔽を含む到達は実射で確認し、必要な調整を記録する。

マス目は文字の読める幅の比率で分割し、境界線そのものも当たる面に含める。柱や装置は壁より手前に描く。天井・床・カウンター・棚板は木目や布が分かる屋台の構造材とし、端に無彩色の空き面が見え続ける場合は屋台の見切りを調整する。既存の隠し対象や風鈴・貯金箱が格子に埋もれないよう、動く部品・輪郭と各装置の共通印で区別する。

## 店主の姿と台詞

人らしい構造を持つ、親しみのある大人の屋台店主。やや丸い頬、鼻筋、上まぶた、口元、首の付け根、袖から出る手首と指のまとまりが横顔でも分かるようにする。紺の法被に生成りの前掛け。帽子部位は、赤い帯の付いた小さな紺の帽子で見分けやすくする。片手に丸いうちわ、もう片手は景品棚を指せる。脚は体重を支える位置に置き、机と重なるときも手と前掛けが見える。ポーズは基本の立ち姿、短いうなずき、片手を上げる案内。呼吸とまばたきは小さく、手ブレや当たり判定の動きに使わない。当たる場所を見分けられるよう、反応する帽子・うちわ・胴・足を見分けられる形にする。モデルは既存の屋台と合う半写実の形・手描き調の柔らかさでまとめる。

吹き出しは白い和紙、細い濃茶の輪郭、尾は店主の頭の横へ短く。店主が見えないときは上端の二段表示に「店主」を添える。照準の中心、残弾、全体図、射撃ボタン、2択に重ねない。長い言語は読みやすく折り返す。発声の代わりに短い紙の音を一度添える案とした。音を切っても話者と全文が分かる。

## 粒とスコアの見せ方

実際の接触点に、木は短い黄土の木くず、金属には細い琥珀色の火花、布には生成りの柔らかな粉。マスは小さな角片、景品では表面に光の短い点と押された方向の小さな粉。通常は数粒・0.2〜0.45秒を目安にし、飛行中の照準や画面全体に光を重ねない。画面外の衝突には既存の矢印を使う。連続接触の重複は一度だけ。大きなセット札が現れても、命中した場所を読み取れるようにする。

セット成立時は屋台の提灯の色を拾った金縁の和紙札を、棚の上部に一枚出す。赤い短冊に「セット完成」、札の中心にセット名、右隣に大きな「＋50点」などの加点。下段に「合計 180点」。複数組は見出しをまとめ、個別に「名前／点／初発見」。次へ進める範囲と詳細を読む範囲を離す。強調は一回だけ、動く版は札が短く開き、小さな紙吹雪が広がる。動きを減らす設定では同じ情報の静止札にする。補給が重なったら札下部に実数を表示し、祝う音は一度にまとめる。セットの有無にかかわらず、一射の短い説明は景品の手前や発射ボタンを塞がない位置に出す。
