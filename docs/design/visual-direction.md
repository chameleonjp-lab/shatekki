# 美術方針（Visual / Claude）

状態：試作v1。色・光・形は Claude が設計した。得点・当たり・HP・弾数・獲得規則には一切影響しない（見た目は物理形状の内側に収める）。iPhone 実機での見え方は未確認。

## 1. 世界観
- 夏祭りの夕暮れ、提灯のあかりが灯る屋台の内側から棚を見る。縦画面で棚3段が画面中央に収まる。
- 木の壁（焦げ茶）、棚板（明るい蜂蜜色）、前縁は赤、天井と上縁は赤白の幕。背景は濃い夕闇（`#1d1424`）で、屋台の外は見えない。
- 棚板の景品置き場には、えんじ色の敷き布（枠ごとに1枚）を敷く。景品は明るい色、背景は暗く暖かい色にして、小さな画面でも輪郭が読める。
- 光は暖色3灯のみ：半球光、前上方の平行光、天井付近の点光。影の投影は行わない（負荷とバッテリー）。景品は下ほど少し暗い焼き込み陰で接地感を出す。

## 2. 画面と視点
- カメラ位置は `layout.camera.eye`、x は立ち位置。注視点は中段の棚板高さ付近で、横は立ち位置の60%だけ追う。手ブレ・照準では動かさない。
- 縦画面の縦画角は52〜70度。横方向が狭くなりすぎないよう画面比に応じて調整する。
- 画面下は手前のカウンター天板、上は天井の幕。主操作UIは画面下端にあるため、中央の棚と照準を覆わない。
- 銃は照準線に沿う細い銃身だけ（長さ12cm）。棚の景品を隠さない。照準の3D十字は、照準線が最初に当たる面（レイキャスト）にそのまま置く。補正や隠しオフセットはない。

## 3. 景品の色と形の言語
| 分類 | 主色 | 形の約束 |
|---|---|---|
| 菓子・食品模型 | 赤・黄・茶・白 | 皿や台の上に載せ、光沢のある丸い塊で読ませる |
| ぬいぐるみ | 動物ごとの特徴色 | 座った丸い体＋頭＋耳。耳の形（丸・長・とがり・たれ）で区別 |
| 乗り物 | 赤・白・黄・緑 | 横向きの長い箱＋車輪。種類ごとに屋根の灯、はしご、ローラー、アームなど1つの目印 |
| 花・自然 | 緑＋花の色 | 鉢や台に立てる。縦に細い輪郭 |
| 海の生き物 | 青・オレンジ・赤 | 横向きの流線形、ひれは三角 |
| 宇宙 | 白・紺・金 | 輪（軌道、リング）か三角翼 |
| 楽器・遊具 | 木目・金・赤 | 円盤は正面向き、柄や脚で縦に伸ばす |

- 全景品が「1つの主色 + 1つの差し色」。同じ段で隣り合う色が近くならないよう、抽選側と調整できる（Task 03、未連携）。
- 素材は物理側の `material`（paper/plastic/wood/cloth/metal/glass/ceramic/rubber）に対応して、つや（Phong）か無つや（Lambert）の共有材質を使う。
- 未登録の `modelKey` は、衝突形状に合わせた単色の基本形＋赤い細帯（「未作成」と一目で分かる）で表示する。落ちずに遊べる。

## 4. 装置・店主・隠し的の見え方
- 装置は1枚の板がレイアウトのボックスそのもの。記号で読み分ける（言語に依存しない）。

| 装置 | 板の色 | 記号 |
|---|---|---|
| 分裂板 | 青緑 | 1本の軸から2本に分かれる矢印 |
| 威力2倍 | オレンジ | 赤い×と白い「2」 |
| 景品変更 | 金のベル | 天井からひもで吊る鈴。ピンクの帯 |
| 減点札 | 暗い紫 | 赤い太い×、上に吊り穴 |
| 弾+2 | 緑 | 白い「+」と「2」、下にコルク2つ |
| 弾種類変更 | 青 | 3つの丸（標準=肌色、重い=鉄色、跳ねる=桃色） |

- 店主はうちわを持つ人形（はっぴ、麦わら帽子、笑顔）。帽子・うちわ・体・足の各メッシュはレイアウトの同名ボックスの内側に収まる。
- 隠し的：だるま（左奥の高所）、招き猫（右壁の高所）。壁の幕の上縁より少し下で、普段は気づきにくい。
- 的の看板（同心円）は壁の平面飾り。当たり判定は無く、厚み2mmの絵。提灯は壁に半分埋めた平たい形（出っ張り5cm以内）。吊り提灯は置かない（当たり判定のない障害物に見えるため）。

## 5. 無音・画面外でも意味が読める表現（Task 12 で拡張）
- 接触：全接触点に小さな閃光（色で対象を区別：景品=淡黄、壁・棚=灰白、装置=水色、店主=桃、隠し的=金、すでに発動済みの装置=灰）。同じ接触は1回だけ。
- 弾：コルク色の円柱＋後ろに薄い尾。威力2倍中はオレンジで少し大きく、重い弾は鉄色、跳ねる弾は桃色。
- 画面外の接触：画面端の方向表示（Task 12）。色・形は上の対象色と同じ。
- 景品の獲得：回収ラインを越えたら即座に消す（ライブ接触の表示）。得点は確定後の `ShotSummary` だけから表示する。

## 6. 予算
- 景品1種 平均430面、最大1,420面前後。1枚の結合ジオメトリ＋共有材質。全景品を同時に出しても約4.3万面。実際の棚は9個で約5,000面。
- 屋台全体（静的）は1メッシュに結合。装置6、店主4、隠し的2、提灯1の別メッシュ。全体の描画呼び出しは約30以下を目標とする（実機で計測、未実施）。


## 演出（Task 12、第2波）

- 接触ごとに素材別の小さな粒（木=茶の欠片、布=ふわ、紙=ひらり、金属=火花、プラ=ぽん、ガラス=水色の光、陶器=白い破片、ゴム=ピンクの弾み）。同時数は粒64・輪12・×印4で打ち止め、古いものから消す。
- 装置6種は粒＋輪＋色で見分ける：分裂=白の放射、威力=橙の輪（コルクも橙）、景品変更=紫の渦と景品のぽん、減点=赤の×印、弾+2=金の上昇、弾種変更=緑の二重輪。作動済みの再接触は灰色の小さな反応だけ。
- 店主は帽子が跳ね、うちわがはためき、体がぐらつき、足が跳ねる。当たるたびに繰り返す（点は初回のみ）。
- 画面外の成功（装置作動・景品接触・店主・隠し的・獲得）は画面端の矢印と短い文言キー（`fx.offscreen.*`）で知らせる。
- 精算後：獲得の光、セット完成の輪とキラキラ、連鎖数の大表示。外れ/惜しい/成功の分類は `classifyShot`（確定した ShotSummary のみ）。スキップは演出だけを省く。
