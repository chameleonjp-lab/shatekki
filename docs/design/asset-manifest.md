# 素材台帳（Visual / Claude）

| 区分 | 場所 | 入手元 | 権利 |
|---|---|---|---|
| 景品100種の3Dモデル（P001〜P100） | `src/view/assets/prize-recipes.ts`、道具 `src/view/assets/kit.ts` | コード内で Claude（Sonnet 5.5）が生成した基本形の組み合わせ。外部の素材、ダウンロードしたモデル、画像、書体は使っていない | 本リポジトリの成果物。第三者の権利を含まない。利用条件の最終判断は利用者 |
| 屋台・装置・店主・隠し的・提灯・銃・照準・閃光 | `src/view/booth.ts`、`shopkeeper.ts`、`scene.ts` | 同上（コード生成） | 同上 |
| 色・配色 | `src/view/assets/prize-recipes.ts` の `C` と各ファイル | Claude が決めた数値。既存ブランドや作品の色を写していない | 同上 |

- 画像・テクスチャ・音声ファイルは今回ありません（頂点色のみ）。音は `src/audio/` のブラウザ合成音のみで、外部の音声ファイルはない。音台帳は `docs/design/audio-ledger.md`。
- 景品名は `docs/prize-candidates.md` の候補名で、キャラクター・商標のある名称は使っていません。形は一般的な玩具・食品模型の意匠で、実在の商品や作品を模していません。
- 新しい外部素材を追加するときは、この表に入手元・ライセンス・取得日を追記してからコミットします。非商用の素材を黙って使わないこと。
- 演出（Task 12）：`src/view/effects.ts` の粒・輪・×印はコード生成の八面体/リング/箱のみ（画像なし）。`src/view/result-vfx.ts` の結果画面の提灯の光は CSS のみ。いずれも外部素材なし。
