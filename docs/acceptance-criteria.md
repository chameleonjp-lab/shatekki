# 受入確認項目

これは確認条件の一覧であり、実行結果は[受入確認の証拠](qa/acceptance-evidence.md)を参照する。今回のD34〜D37については[修正書のCH-AC01〜44](changes/2026-11-06-expanded-gameplay-requirements.md#12-変更後の確認条件)を追加した。下表の状態欄を過去の試験結果の代わりに使わない。変更後の条件は未実装・未実施である。

| AC02 | 基本 | 景品100種類に対し2景品セット300件を持つ。既存3景品100件を残す提案では合計400件。各セットは所定の異なる景品を参照する。 | 変更後未実施 |
| AC03 | 操作 | 位置選び・装填・照準の段階が区別され、発射して初めて弾が1発減る。 | 未実施 |

| AC12 | 抽選 | 難易度・種類の偏りを調整し、再出現を禁止せず連続を抑えることが設定・記録で分かる。 | 未実施 |

| AC15 | 分裂 | 分裂は飛んでいるコルクだけを増やし、所持弾や発射回数を増やさない。 | 未実施 |
| AC16 | 仕掛け | 威力倍・景品変更・減点・所持弾＋2・弾種類変更が、確定した詳細どおり発動する。同じ特殊装置は元弾と分裂弾を通じて一射1回。 | 未実施 |
| AC17 | 上限 | 追加弾の累計は10発以内、発射回数は最大20回。分裂と区別して検査する。 | 未実施 |

| AC19 | 終了 | 反射・分裂の上限でも有限時間で終わる。既に落下中の景品には短い猶予を設け、周期的に動く装飾が止まるのは待たない。 | 未実施 |
| AC20 | セット | 複数射にまたがって各セットの必要種類数（2種類または3種類）を取ると成立し、順番を問わない。同種の複数個では代用しない。 | 変更後未実施 |

| AC25 | 店主 | 同一部位・同一隠し対象への加点は初回だけ。質問の回数を別管理し、200質問と2択はCH-AC11〜17で確認する。 | 変更後未実施 |
