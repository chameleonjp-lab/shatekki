# 追加機能の釣り合いの測定（試作値・自動の打ち手）

2026年11月6日。`tests/integration/expanded-balance-probe.test.ts` の結果です。毎回の数値は `test-results/expanded-balance-probe.json` に出ます（このファイルはコミットしません）。

## 何を測ったか

本物の司令役・物理・効果計画・確定処理を通して、同じ24個の乱数の種で、旧ルール（`official-v1`、rules-v1）と追加機能の試作（`expanded-proposed`、`rules-v2-proposed-r001`）のゲームを最後まで自動で遊ばせました。打ち手は、立ち位置と狙う先をでたらめに選びます。新しいルールでは、約1割を店主、約2割を背景マスへ向け、残りは景品を狙います。装填は成功範囲の近くで止め、照準の揺れが小さいうちに撃ちます。質問にはAかBをでたらめに答えます。

これはNode上のRapierでの測定です。iPhoneのSafariでも、実機でもありません。打ち手は人の腕前をまねたものではないので、数字は「この試作値でこう動いた」という記録であり、目標値ではありません。24ゲームでは、セットの成立確率を言い切れません。

## 結果（24ゲームずつ）

| 項目 | 旧ルール rules-v1 | 試作 rules-v2-proposed-r001 |
|---|---:|---:|
| 1ゲームで取った景品（平均） | 3.21 | 2.83 |
| 得点（平均／中央） | 55.6／50 | 73.8／60 |
| 発射数（平均） | 10.0 | 10.1 |
| 3景品セットの成立（1ゲーム平均） | 0.04 | 0 |
| 2景品セットの成立（1ゲーム平均） | — | 0.25 |
| セットが1つ以上成立したゲーム | 1 | 5 |
| 店主の質問（1ゲーム平均） | — | 1.42 |
| 使った背景マス（1ゲーム平均） | — | 1.79 |
| 1ゲームの計算時間（Node、平均） | 111ミリ秒 | 257ミリ秒 |

新しいルールでは、取れる景品の数はやや減りました。打ち手が約3割の弾を店主と背景マスへ向けたことが、理由の一つと考えられます（意見）。それでも2景品セットのおかげで、セットが成立したゲームは24回中1回から5回へ増えました。弾を3発減らす効果を引いて7発で終わったゲームが1回、弾が増えて12〜13発撃てたゲームが2回ありました。どの回も、弾数の検査式（発射数＋残弾＋減った弾＝初期10発＋追加分）が成り立っていました。

## 景品の種類変化と延期

品揃えの変更などで、景品の種類を変える予定は767件ありました。そのうち641件はその射で変わり、126件（約16%）は形が棚や他の景品と重なるため延期になりました。仕様確認メモ（SHK-20261106-CLAUDE-004 の1）で心配した「ほぼ毎回延期」ほど多くはありませんでした。ただ、どの種類の組み合わせで延期が多いかは、まだ数えていません。

## 次に測ること

- iPhone Safari実機での毎秒のコマ数（36景品・36マス・最大8コルク）と、両端・上下段・店主への狙いやすさ
- 人が遊んだときの景品の取れ方（自動の打ち手の数字だけで点数や確率を決めない）
- 延期が多い種類の組み合わせと、仕様確認メモの案A・案Bを選んだ場合の差
