# 性能の記録（AC40、Task 17）

2026-11-06 Opus。iPhoneでの測定ではない。実機の確認は `docs/qa/iphone-checklist.md` の項目17で行う。

## 目標

iPhone 17 ProのSafariで、遊んでいる間なめらか（毎秒60コマ）を目指し、少なくとも毎秒30コマを保つ。一射の処理は、反射・分裂・落下猶予の上限から、最長でも `飛行4秒＋静止待ち5秒＋落下猶予1.2秒` 以内に終わる。

## 測定結果（この実行環境）

| 項目 | 値 | 条件 |
|---|---|---|
| 物理計算（1コマ＝固定刻み2回） | 中央値0.07〜0.12ms、95%点0.29〜0.59ms、最大2.4ms | Node＋Rapier、最も重い一射3種（跳ねやすい弾で分裂板、通常弾で分裂板、壁沿いの反射）。`tests/integration/performance.test.ts` |
| 一射の長さ | 1.0〜1.8秒、上限10.2秒以内 | 同上 |
| 描画のコマ間隔 | 中央値33ms、95%点50ms | ヘッドレスChromium（ソフトウェアGPU）、402×874。`tests/e2e/performance.spec.ts` |
| 場面の大きさ | 三角形約9,900、メッシュ24、描画命令19 | 景品9個の通常の場面 |
| 最初に読み込む量 | 69KB（圧縮後19KB） | 物理と描画は後から読み込む（圧縮後で約1.8MB） |

物理計算の時間は、一度空撃ちして処理を温めてから測る。壁時計の値は機械や同時に動く試験によって変わるため、自動試験では記録だけを残し、合否は「1回の計算が50msを超えて止まったようになる」異常だけで判定する（CIで最初の版が8msの線を超えて失敗したため、2026-11-06に見直した）。

速いコルクが薄い棚をすり抜けないことは、`tests/unit/collision.test.ts` で確かめている。ソフトウェアGPUのコマ間隔は実機より遅いのが普通で、この値から実機の性能は判断できない。
