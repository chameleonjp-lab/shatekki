# シャテッキ｜新しい操作と屋台の計画を反例で確認した記録

2026年11月19日。初稿を別の担当が読み、main `17d6f5c` の現在の遷移・保存・座標・確定結果と照合した。以下は[要件](../changes/2026-11-19-aim-first-stall-requirements.md)と[実装計画](../superpowers/plans/2026-11-19-aim-first-stall.md)に適用した修正と、実装時に試す反例。

| 反例 | 計画への反映と確認する場面 |
|---|---|
| 位置の確定を外すと最後の一発の二重丸が消え、威力を決める前は軌道案内も出せない。現行は `CONFIRM_POSITION` と仮の `FIRE` に依存する。 | 二重丸を照準の時点から出し、左右に追従、威力を選ぶ間に固定する。取消では消費せず、発射保存後にだけ一回使う。威力選択前も副作用なしでFX098とコルク半径を含む装置の案内を出す。手ブレ由来の4効果は威力区画に移し、FX082は既存の全リセットを保つ。上端を越える範囲、最後の弾と取消、左右端で試す。[的の入口](../../src/core/rewards.ts)・[軌道案内](../../src/app/controller.ts) |
| 同じx/yの左右壁のマスがすべて同じ場所として扱われる。角で接触しただけで2マスを消費しうる。 | 背面は横と高さ、側面は奥行きと高さ。三面の共通座標から、同時角の順序と外周の含め方を決める。一つの接触は一つのマス。別のコルク・後から来た反射は別の接触。境界の両側、重なる装置、分裂弾で試す。[現行の物理](../../src/sim/world.ts) |
| 現行の保存は「位置→威力→照準→発射」を前提にする。照準だけを変えて再読み込みすると、その操作が記録されていない。 | 新版だけ入口と保存検査を変更。指を離して完了した位置・照準を保存。発射保存に失敗したときも押した刻みの威力を保持し、再試行で値を取り直さない。早い連打、保存済みで応答だけ消失、二つのタブ、横向きからの復帰を試す。[保存の検査](../../src/persistence/indexed-run-repository.ts)・[進行状態の検査](../../src/core/session.ts) |
| 現行寸法では左右の壁の手前と中央で、見た目を変えても直接の射が届かない。人型店主の腕や手が旧来の小さな箱からはみ出すおそれもある。 | [描写仕様](../design/2026-11-19-aim-first-stall-art.md)に位置・銃口・射角の開始値を明記した。各面の上下・端と側面各列を実射し、隠れる面の扱いを記録。店主の見える形と当たる形を共有し、各部位、背後のマス、手前の装置を狙い分けて確認する。[現行の寸法](../../src/contracts/layout-v2.ts) |
| 現行の確定データだけでは使用済みマスに当たったことや、外へ抜けた方向が分からない。セット初発見と既存側の補給が重なると、受け取った発数が効果札の短縮行に入る。 | 接触と出口の事実を確定要約に保存。物理量に合う一言を1射に一つ。セットの各加点・確定総得点と、全発生元から実際に得た弾を同じ札へ出す。無接触、使用済み、最後の発射、6件以上の効果、再読込で比較する。[確定データ](../../src/contracts/events.ts)・[効果札](../../src/ui/effect-results.ts) |

追加で、台詞の抽選とゲームの抽選を分けた。発射待ち・質問・停止・他の案内の間は台詞を積み上げない。台詞に確定していない得点・弾を言わせず、条件のある原稿をその状態でだけ使う。試作値は要件に記録し、正式採用時の実機と人による試遊を別途確認する。
